# Appunti di Basi di dati (2k27)

Appunti del corso di Basi di dati, scritti come vault di [Obsidian](https://obsidian.md).

## Come aprirli
1. Scarica il repository: `git clone https://github.com/BrugnoliDavide/appunti_Basi_di_Dati_2k27.git` (oppure **Code → Download ZIP** ed estrai lo zip).
2. Installa e apri Obsidian.
3. Scegli **"Apri cartella come vault"** e seleziona la cartella scaricata.
4. Parti dalla nota **`00 Indice`**.

Formule e diagrammi si vedono già senza plugin aggiuntivi.
